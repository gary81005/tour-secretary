# Roadmap

每個 milestone 開一個 branch；開始前先針對該階段細節確認需求，完成後跑 build / lint / test 再 review。

|        | 內容                                                                                                                                                       | 狀態    |
| ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ------- |
| **M0** | 基礎建設：shadcn/ui + Tailwind、Supabase SSR、next-intl、Prettier / ESLint / Vitest、React Compiler、嚴格 TS、文件                                         | ✅ 完成 |
| **M1** | 登入（Email 驗證碼／連結 + Google OAuth）、行程增刪改查與垃圾桶、手動編輯（天 → 項目，含時段、類別、地點、備案、時區、拖拉排序）、住宿、提醒事項、旅伴限制 | ✅ 完成 |
| **M2** | xlsx 範本匯入（新建／附加／覆蓋、預覽、復原上次匯入；ADR 0008）                                                                                            | ✅ 完成 |
| **M3** | MapProvider（Google）：地點搜尋、營業時間、交通路線                                                                                                        |         |
| **M4** | 旅途模式：「現在／下一站」、交通指南、PWA、離線唯讀                                                                                                        |         |
| **M5** | 旅伴邀請與權限                                                                                                                                             |         |
| **M6** | 定位落後提醒 + 手動回報臨時事件（不用 AI 的調整工具）                                                                                                      |         |
| **M7** | Claude：從零規劃對話、非固定格式匯入、臨時事件自動提案                                                                                                     |         |

之後再考慮：候選住宿比價、預算記帳、en-US 等其他語系、韓國 Kakao provider、完整離線編輯。

M1 留到之後處理（細節見 ADR 0005「M5 之前要處理」）：

- M5 前：接自己的 SMTP；決定哪些操作只有 owner 能做（移到垃圾桶、平移、修改起訖日、增刪天、匯入覆蓋與復原），policy 與日期函式一起改。
- 跨午夜的項目（夜車、紅眼班機）目前只能填開始時間。
- 沒有 `global-error.tsx`：root layout 本身出錯時是 Next 預設頁面。

M2 留到之後處理：

- 匯入不拆地點（ADR 0008 Q5），M3 接上地圖搜尋後再補。
- 格式不固定的行程表（例如範例檔第 14 列以後的區塊）交給 M7 的 AI 匯入。
- 匯入資料超過 Server Action 的 1 MB 上限時只在預覽擋下，提示拆檔分次附加；實際遇到再考慮調高 `serverActions.bodySizeLimit`。
