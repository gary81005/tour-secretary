# 0008 xlsx 匯入範本

- 狀態：已採用（2026-11-04）；M2 實作

## 背景

使用者現有的行程表（`docs/samples/東北秘境探險.xlsx`）把七個區塊放在同一張工作表；每日行程是**橫向**排列：第 1 列日期、第 2 列城市、每天 2 欄（時段 | 內容）。

## 決策

- 自訂標準範本，以 exceljs 依規則解析（只用動態 `import('exceljs')` 載入）。
- 第一張工作表**沿用使用者的橫向格式**：第 1 列日期、第 2 列城市、每天 2 欄（時段 | 內容）。
- 住宿、提醒事項、備案、旅伴限制各自一張結構化的工作表。
- 匯入後先在畫面上預覽、修正，確認後才存檔。
- 格式不固定的檔案（例如目前這份範例）交給 M7 的 AI 匯入處理。
