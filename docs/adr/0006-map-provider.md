# 0006 地圖服務：MapProvider 介面

- 狀態：已採用（2026-11-04）；M3 細節於 2026-11-11 定案

## 背景

主要旅遊地區是日本、韓國等亞洲地區。Google Maps 在韓國受法規限制，沒有開車與步行路線，地點資料也不如 Naver / Kakao。

## 決策

- 定義 **MapProvider** 介面（地點搜尋、地點詳情與營業時間、交通路線），呼叫端只依賴介面。
- 先實作 **Google Maps Platform**（Places + Routes）。在韓國時交通指南只顯示大眾運輸，並提供「用 Naver Map / KakaoMap 開啟」的連結。
- 之後補 Kakao（Kakao Local / Kakao Mobility）實作，依地點所在國家選擇 provider。
- 地圖 API 金鑰只在伺服器端使用。

## M3 細節

設定步驟見 `docs/setup/google-maps.md`；純邏輯在 `src/lib/maps/`（有測試）。

### 使用的 API（Q2、Q3）

- **Places API (New)**：地點搜尋（Autocomplete）、地點詳情（座標、地址、營業時間）。
- **Routes API**：步行與開車時間（Essentials，不考慮即時路況）。大眾運輸在日本算不出來（實測 `TRANSIT` 回傳空結果），所以每一段附「查電車」的 Google 地圖連結。
- **不內嵌地圖**：每個地點與每一天各有「在 Google 地圖開啟」的連結（Maps URL 不需要金鑰）。當天路線連結最多 9 個中途點、不支援大眾運輸，適合看地點分布。

### 地點連結（Q4、Q5、Q6、Q11、Q14）

- `item_places` 與 `stays` 各加：地圖服務（目前只有 `google`）、地點 ID、座標、座標抓取時間。
- **只存地點 ID 與座標**（服務條款：地點 ID 可以永久保存，座標最多 30 天）。營業時間、地址顯示時才查，伺服器短暫快取。
- 座標超過 30 天視為沒有，下次存檔時重新查；每天的清理排程（`purge_deleted_rows`）把超過 30 天的座標從資料庫清掉。抓取時間由 trigger 限制不能晚於現在，瀏覽器直接寫入也無法延長期限（2026-11-12 review 後調整）。路線計算直接用地點 ID，不依賴存下來的座標；座標只用來讓搜尋偏向行程的地區（之後 M6 的定位提醒也會用）。
- 存檔時瀏覽器只送地點 ID，座標由伺服器向 Google 查，不相信瀏覽器傳來的座標。
- 名稱預填 Google 的名稱，可以改成自己的稱呼，仍保持連結；也可以取消連結，變回純文字。存下來的名稱是使用者可以修改的文字（行程裡的稱呼），不是 Google 地點資料的副本；畫面不會用它去比對或更新 Google 的資料（2026-11-12 review 後確認保留）。
- 住宿的「地址或地點」文字保留使用者原本寫的，不改成 Google 的地址。選定地點時也不自動帶入 Google 的地址（存進資料庫違反服務條款）；改成在住宿已連結、地址空白時，住宿卡片與「今晚住」顯示 Google 的地址（顯示時查，不存）。
- 入口：項目表單的地點欄可以搜尋；另有「幫我找地點」：依「、，/→或」拆開標題，每一段列出前 3 個候選，勾選後加入。「或」表示二選一，可以只勾一個。M2 匯入的純文字地點也用這個方式連結。

### 搜尋（Q10）

- 語言 `zh-TW`。
- 偏向當天已連結的地點或當晚住宿的座標；都沒有時，依當天時區推測國家（`regionCode`）。
- 「幫我找地點」也用 Autocomplete（不用 Text Search，避免 Pro 級費用）。搜尋框用 session token：選定後的地點詳情結束這個 session，建議本身不另外計費。

### 營業時間（Q8）

- 依項目所在日期顯示：7 天內用 `currentOpeningHours`（含特殊營業日），之後用 `regularOpeningHours`。
- 標記：「當天公休」、有精確時間但不在營業時間內時「可能未營業」、Google 標示暫停或永久歇業時「已歇業」。

### 移動時間（Q9）

- 計算的段：前一個項目的最後一個地點 → 下一個項目的第一個地點（沒有連結地點的項目跳過）；一天的開頭從前一晚的住宿出發，結尾回到當晚的住宿。同一項目內的多個地點不算。
- 打開某一天時自動計算當天各段，伺服器短暫快取。
- 先算步行；步行超過 30 分鐘才另外算開車。
- 兩張項目卡片之間顯示一行，例如「步行 12 分・查電車」。

### 韓國（Q13）

- 只用 Google：地點搜尋與營業時間照常；不算移動時間，改附 Naver Map／KakaoMap 連結。
- 每一段附 KakaoMap／Naver Map 連結，都用**目的地名稱**搜尋，不帶座標：服務條款不允許把 Google 的資料（包括座標）用在其他地圖服務（2026-11-12 review 後調整，原本兩端有座標時開 KakaoMap 路線）。
- 以當天時區（`Asia/Seoul`）判斷。

### 來源標示

- 沒有搭配 Google 地圖顯示 Google 的資料（搜尋建議、「幫我找地點」候選、營業時間、地址、移動時間）時，標示 Google Maps 官方標誌（`GoogleMapsAttribution`）。規範：標誌優先，只有放不下時才用文字「Google Maps」；用官方檔案、高度 16–19px、四周留白，素色背景用無外框版。
- 單日畫面與住宿分頁在頁尾標示一次；搜尋框與「幫我找地點」在清單下方標示。

### 沒有金鑰時（Q15）

- App 照常運作：地點欄退回純文字輸入，不顯示營業時間、移動時間、「幫我找地點」。Google 地圖連結照樣顯示。

### 費用

- 個人使用都在每月免費額度內；唯一的風險是營業時間（Place Details Enterprise，每月 1,000 次免費）。
- Google Cloud 設每日上限與 US$1 預算警示（`docs/setup/google-maps.md`）。伺服器快取只在各 Vercel 執行個體的記憶體裡，不一定命中，真正擋住費用的是每日上限。
